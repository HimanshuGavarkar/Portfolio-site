# Hero Image

Replace `hero-portrait-edit.png` with your edited portrait.

Requirements:

- Keep the filename exactly `hero-portrait-edit.png`.
- Keep PNG format with transparency.
- Preserve the original face, hair, beard, shoulders and shirt.
- Avoid a rectangular background or white halo.
- Keep the image roughly square for the current hero crop.

The website hero already points to this file, so replacing it updates the portrait automatically.
